Zero | X - V1

Privacy Policy

Last Updated: August 12, 2026

1. Introduction

This Privacy Policy explains how Zero | X - V1 ("Zero | X", "the Bot", or "the Service") collects, uses, stores, and handles information when the Bot is added to or used within a Discord server.

By using Zero | X, you acknowledge that you have read and understood this Privacy Policy.

If you do not agree with this Privacy Policy, you should remove Zero | X from your Discord server and discontinue its use.

2. Information We Collect

Zero | X may process certain information necessary to provide its security and moderation features.

2.1 Discord User IDs

Zero | X may collect and store Discord User IDs.

User IDs may be used for purposes including:

  • Identifying users involved in security events.
  • Managing trusted or whitelisted users.
  • Applying security configurations.
  • Supporting moderation and security features.
  • Maintaining the functionality of the Bot.

2.2 Discord Server / Guild IDs

Zero | X may collect and store Discord Server (Guild) IDs.

Server IDs may be used to:

  • Identify servers where Zero | X is installed.
  • Associate security configurations with the appropriate server.
  • Manage server-specific settings.
  • Maintain whitelist and trusted-user configurations.
  • Provide security features specific to individual servers.

2.3 Usernames and Display Names

Zero | X may temporarily process usernames or display names when necessary to identify users in security alerts, logs, or other Bot functions.

Usernames and display names are not currently intended to be permanently stored as a separate user profile.

2.4 Message Content

Zero | X does not currently store message content as part of its normal operation.

The Bot may inspect Discord events or messages when necessary to provide features such as anti-spam or mass-mention protection, but message content is not currently intended to be permanently stored by Zero | X.

3. Security Alerts and Logging

Zero | X may send security alerts to a private security or logging channel configured by a server administrator.

These alerts may contain information such as:

  • Discord User IDs
  • Discord Server IDs
  • Usernames or display names
  • The type of security event
  • The action detected
  • The action taken by the Bot
  • Relevant timestamps or event information

Security alerts are intended to help authorized server administrators investigate and respond to security incidents.

At the current time, security events are primarily sent to the configured Discord security channel.

Future versions of Zero | X may introduce database-based storage of security logs. If this occurs, this Privacy Policy will be updated to describe the additional storage, retention, and handling practices.

4. Server Configuration

Zero | X is being developed to support server-specific security configurations.

Depending on the current version and enabled features, configuration information may include:

  • Security thresholds
  • Trusted or whitelisted Discord User IDs
  • Security channel information
  • Lockdown settings
  • Anti-raid settings
  • Anti-spam settings
  • Anti-nuke settings
  • Other security-related preferences

Configuration storage and management are currently under development and may change as Zero | X evolves.

5. Data Storage

Zero | X currently uses JSON files for applicable data storage.

Stored information may include information necessary to maintain Bot configuration, trusted users, server-specific settings, or other functionality.

We take reasonable measures to protect stored information from unauthorized access or misuse.

The storage system may change in the future as Zero | X develops. For example, certain security information may eventually be stored in a database.

6. Developer Access

The Zero | X development team may have access to stored information when necessary to:

  • Develop and maintain the Bot.
  • Troubleshoot technical issues.
  • Investigate security problems.
  • Improve Bot functionality.
  • Maintain or repair data storage.
  • Respond to legitimate requests concerning the Service.

Access to stored information should be limited to purposes related to the operation, maintenance, security, and development of Zero | X.

7. IP Addresses

Zero | X does not currently state that it collects or stores IP addresses as part of its standard operation.

IP-related functionality may be introduced in a future version of the Service.

If IP addresses or similar network information are collected in the future, this Privacy Policy will be updated to explain what information is collected, why it is collected, how it is stored, and how long it is retained.

8. Data Retention

Information is retained only for as long as it is reasonably necessary for the operation of Zero | X and its security features.

Server-specific information may be retained while Zero | X is installed and being used in a server.

When a server removes Zero | X, the developers intend to delete stored server-specific information associated with that server, subject to any information that may be required to be retained for legitimate security, legal, or technical reasons.

9. Data Deletion Requests

Server owners or authorized representatives may contact the Zero | X development team to request deletion of information associated with their server.

Requests may be reviewed to verify that the requester has appropriate authority over the relevant server.

Data deletion contact: aaronmart2022@icloud.com

10. Data Sharing

Zero | X does not currently intend to sell personal information.

Information processed by Zero | X may be visible to authorized administrators of the Discord server in which the Bot operates, particularly when information is included in security alerts or logs.

Information may also be disclosed when required by applicable law or when necessary to protect the security, rights, or operation of the Service.

11. Discord

Zero | X operates through Discord and relies on Discord's platform and APIs.

Your use of Discord is also subject to Discord's own Terms of Service and Privacy Policy.

Zero | X does not control Discord's collection, processing, or storage of information.

12. Security

Reasonable measures are taken to protect information handled by Zero | X.

However, no electronic storage system or internet-based service can guarantee absolute security.

Users and server administrators should also take appropriate steps to protect their Discord accounts, server permissions, authentication credentials, and other security-sensitive information.

13. Children's Privacy

Zero | X is intended to be used through Discord and does not knowingly seek to collect personal information from children for purposes unrelated to providing the Service.

Users should comply with Discord's age requirements and applicable laws when using Discord and Zero | X.

14. Changes to This Privacy Policy

This Privacy Policy may be updated as Zero | X develops, introduces new features, changes its storage systems, or changes the way information is processed.

Updated versions will be published on the official Privacy Policy page.

The Last Updated date at the top of this page will be changed when material updates are made.
